# Infinite Adventure Engine (Infin8)

**Description:** An infinite choose-your-own-adventure game with real-time AI image generation, dynamic inventory, and a lore chatbot.

## Overview

Infin8 is an immersive, infinitely generated text and visual adventure engine. By leveraging real-time AI image generation, dynamic inventory tracking, and an integrated lore chatbot, it delivers a uniquely personalized and endless gaming experience.

## Features

*   **Infinite Narrative Generation:** Procedurally driven storylines that adapt to player choices.
*   **Real-Time AI Image Generation:** Visualizes scenes, characters, and items on the fly.
*   **Dynamic Inventory:** Stateful tracking of items, stats, and player progress.
*   **Lore Chatbot:** Interactive companion to explain world history and mythology.

## Getting Started

### Prerequisites

*   Node.js

### Local Development

1.  **Install dependencies:**
    ```bash
    npm install
    ```
2.  **Configure API Key:** Set your `GEMINI_API_KEY` in the `.env.local` file.
3.  **Run the application:**
    ```bash
    npm run dev
    ```
